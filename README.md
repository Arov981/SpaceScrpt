# SpaceScript-Web

Web companion app for **SpaceScript** — the multi-AI studio for Blender + Roblox Studio.

This repo contains the **Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui** source
for the SpaceScript web app: hero, feature grid, an interactive Studio
(tools / skills / workflows / themes / ideas / commands / connectors /
console / mission-control tabs), an AI agent demo powered by
`z-ai-web-dev-sdk`, downloads, changelog, and credits.

## Stack

- Next.js 16 (App Router)
- TypeScript 5
- Tailwind CSS 4 + shadcn/ui (New York)
- Prisma ORM (SQLite)
- Framer Motion, Radix UI, Lucide icons
- `z-ai-web-dev-sdk` for the agent endpoint

## Getting started

```bash
bun install
bun run db:push
bun run dev
```

The app runs on `http://localhost:3000`.

## Notes on this upload

This repository was pushed file-by-file through the GitHub REST API (the
MCP integration does not support raw `.zip` uploads, and new-repo
creation was blocked by a missing OAuth scope, so files were pushed
into the existing `SpaceScrpt` repo).

The following were **not** pushed (build artifacts, binary, or over the
API's practical limits) and should be regenerated locally:

- `bun.lock` — regenerate with `bun install`
- `src/lib/spacescript/generated-catalog.json` — large generated catalog
  (~1 MB), regenerated by the SpaceScript build script
- `node_modules/`, `.next/`, `db/*.db` — never committed (see `.gitignore`)

Everything else — app routes, components, hooks, lib, prisma schema,
mini-services, public assets, and all root config — is included.
